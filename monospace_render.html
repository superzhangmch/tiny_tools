等宽文本渲染器

粘贴在终端 / 等宽字体环境下生成的文本（可夹杂中英文，如 ASCII 表格、框线图、代码对齐输出）。
字体模式：直接用「中文=2×英文宽」的等宽字体（Maple Mono CN，按需加载）整段渲染，零计算，就是终端的观感； 网格模式：逐字符按 wcwidth 锁到网格，不依赖任何字体。
注意：若文本是 LLM 生成的表格，它补空格时常把中文数成 1 列——源文本本身就歪，放真终端里也歪，渲染救不了。 这种情况点 修复 LLM 表格，按真实显示宽度重排后回填输入框（可复制走）。 转 Markdown 表格：把终端框线表格（┌─┬─┐ / │ 分隔）转成 Markdown 表格，同样回填输入框。
