W(x) = Σ aⁿ cos(bⁿπx)（连续函数的一致收敛级数 ⇒ 处处连续）；当 ab > 1 + 3π/2 ≈ 5.712 时处处不可导（Weierstrass 1872；Hardy 1916 放宽到 ab ≥ 1）。 拖一个框 / 滚轮放大：无论放大多少倍，曲线永远毛糙、永不变直——"切线"从不出现。 相位 bⁿπx 用 BigInt 精确取模计算，放大到窗宽 10⁻¹² 看到的仍是真函数，不是浮点噪声。项数按"截断尾部 < 屏幕上 1/3000 像素高度"自动选取（读数在上方）。
狄利克雷函数 1ℚ(x)：有理数处 = 1，无理数处 = 0。它没法直接画——图上画的是逼近序列 f(x) = [cos(m!·πx)]2n：先让 n→∞（尖峰缩成分母整除 m! 的有理点，红点标出），再让 m→∞（红点铺满全部有理数），逐点极限恰是狄利克雷函数。灰带是每个像素列内函数的真实取值范围（min–max，防走样）。 处处不连续：任何点的任意小邻域内同时有有理数（f=1）和无理数（f=0），振荡恒为 1。 黎曼不可积：任何分割的每个小区间上 sup=1、inf=0 ⇒ 上积分=1、下积分=0，永不相等。 勒贝格可积：ℚ 可数 ⇒ 测度 0 ⇒ ∫ = 0。蓝点是几个无理数样本（√2−1, π−3, e−2, φ−1）。
托梅函数：f(p/q) = 1/q（既约分数），f(无理数) = 0。与狄利克雷相反：在每个无理点连续、每个有理点不连续。 道理全在 ε 横线上：高于 ε 的点只有有限个（分母 q ≤ 1/ε 的既约分数，计数显示在上方）——避开这有限个点，函数值全部压在 ε 之下，这就是无理点处的连续性；也因此它黎曼可积且 ∫₀¹ = 0。拖框/滚轮放大看：任何小窗口里也只有稀疏的高点。
康托函数（魔鬼阶梯）：连续、单调不减、从 0 爬到 1，但导数几乎处处 = 0——在康托集补集的每个开区间（挖掉的中三分段）上恒为常数，这些平台的总长度 = 1。 全部"爬升"都发生在测度为 0 的康托集上：一个不靠"斜率"就完成上升的连续函数（它不是绝对连续的，∫c′ = 0 ≠ c(1)−c(0)）。 橙色虚线是第 k 层迭代的折线逼近（拖 k 看收敛）；拖框/滚轮放大——阶梯里嵌着缩小的阶梯，无穷自相似。
