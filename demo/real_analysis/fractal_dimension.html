分形维数 —— 维数不是"有几个坐标"，而是"尺度缩小时，量变大得多快"的那个指数。三种定义 + 真数格子验证

先把"维数"改写成一句话：把尺子缩小到 1/k，需要的块数变成 kd 倍 —— 这个 d 就是维数。
线段缩一半要 2 块（2 = 21）、正方形要 4 块（4 = 22）、立方体要 8 块（8 = 23）。 于是对由 N 个比例为 r 的副本拼成的自相似集，直接解 N·rd = 1： d = log N / log(1/r)（相似维数 / similarity dimension）。
这个式子对线段和正方形给出 1 和 2（和常识一致），对科赫曲线给出 1.2619 —— 同一个定义，只是答案不再是整数。 右图是"把红色那一块放大 1/r 倍"，得到的正是整体：副本数 N 和比例 r 都能在图上数出来，不是背下来的。
迭代层数 k 高亮第几个副本
整体（第 k 层）：红色 = 被高亮的那 1 个副本， 它是整体的 r 倍缩小版；灰色虚框是它的包围盒。
把红框放大 1/r 倍：和左图一模一样（少一层细节 —— 因为左图只画到第 k 层）。 这就是"自相似"的操作性定义。
质量–尺度 log-log：横轴 log(1/尺度)，纵轴 log(块数)。 斜率就是 d。灰虚线是斜率 1 和 2 的参照 —— 分形夹在整数之间。
相似维数只对"严格自相似 + 副本几乎不重叠（开集条件）"的集合有效。 它是个"作弊算法"：不用做覆盖的下确界，直接读 N 和 r。对于随机分形（布朗轨迹、海岸线）或只是"看起来粗糙"的曲线， N 和 r 根本不存在，就必须回到 ② 的盒计数或 ③ 的豪斯多夫定义去实测。
龙曲线是个提醒：N=2、r=1/√2 ⟹ d = log2/log√2 = 2。图上画的折线是它的逼近（每层 2k 段、自不相交）， 但极限集是一块有内点、有面积的"龙瓷砖"（能无缝铺满平面），所以 2 这个数是实打实的。
想看"维数认不出形状差别"，对比 ② 里的康托尘和科赫曲线：两者维数都是 1.2619， 一个是完全断开的尘埃（拓扑维数 0），一个是连通曲线（拓扑维数 1）。分形维数不认识连通性。
盒计数维数（Minkowski–Bouligand）：拿边长 ε 的方格网盖住图形，数非空格子数 N(ε)， dbox = limε→0 log N(ε) / log(1/ε)。 实操就是：对一串 ε 画 log N(ε) 对 log(1/ε) 的散点，拟合直线的斜率就是维数。
本页是真在数：图形先栅格化成 1024×1024 的 0/1 位图，再用 2×2 逐级合并得到 ε = 2j/1024 各档的精确格子数。
两端必然坏掉，这不是 bug，是有限尺度的宿命：ε 接近整体尺寸时只剩几个格子（N 从 4 掉到 1 这种）， 斜率被整数跳变支配，没有统计意义；ε 小于"构造深度 / 线宽 / 像素"时，图形在那个尺度下已经是光滑的 （曲线斜率→1、实心块→2）。 所以要看局部斜率的平台，并只在平台上拟合 —— 这正是真实数据（海岸线、星系、血管）上做分形分析的标准姿势。
看 ε = 2j/1024 的网格，j 拟合窗口 H
图形 + 当前 ε 的网格：蓝格 = 非空格子（被数进 N(ε) 的）。 手绘档可以直接在图上画线，实时出维数。
log-log 与拟合：橙点 = 实测 log₂N(ε)，红线 = 在拟合窗口内的最小二乘直线， 灰虚线 = 理论斜率。只在平台上拟合。
局部斜率 log₂(Nj/Nj+1)：相邻两档之间的斜率（横轴越往右 ε 越小）。 中间那段平台才是维数；左端格子只剩几个，斜率乱跳；右端细节用完，掉向 1（曲线）或 2（实心）。
豪斯多夫测度（这才是原始定义，盒计数只是它的廉价替身）： Hsδ(A) = inf { Σi |Ui|s : A ⊂ ⋃Ui, |Ui| ≤ δ }， 再令 δ→0 得 Hs(A)。注意指数 s 是连续参数，不必是整数。
关键事实：把 s 从小往大扫，Hs(A) 会在某一个 s = d 处从 ∞ 跳到 0，这个临界值就是 豪斯多夫维数 dimHA = inf{s : Hs=0} = sup{s : Hs=∞}。 只在 s = d 这一点上 Hs 可能是有限的正数。
左图就在扫这个相变：对自相似集用自然覆盖（第 k 层的 Nk 块，每块直径 rk）， Σ|U|s = (N·rs)k —— 一个几何序列，公比 N·rs 大于/等于/小于 1 三种命运一目了然。
试探指数 s
Σ|Ui|s 随覆盖层数 k（纵轴 log₁₀）。公比 N·rs： >1 ⟹ 爆到 ∞（s 太小，"量"无穷多，说明 A 比 s 维大）； <1 ⟹ 掉到 0（s 太大）； =1 ⟹ 水平线，只有这一个 s 让"量"既不 0 也不 ∞。
Hs(A) 对 s 的相图：一个阶跃函数，跳变点 = 维数。 红竖线是你当前的 s。维数是"相变点"，不是"量" —— 这是豪斯多夫定义最漂亮的地方。
自然覆盖只给上界。下界要用"质量分布原理"：若 A 上有质量 μ(A)=1 的测度，且存在常数 c 使 μ(U) ≤ c·|U|d 对一切小集合 U 成立，则 Hd(A) ≥ 1/c > 0。 （道理一行：任何覆盖 1 = μ(A) ≤ Σμ(Ui) ≤ cΣ|Ui|d。）
下图对康托集实测这个不等式：μ 取康托测度（每层 2k 块各分 2−k 质量，其分布函数正是康托函数）， 随机抽几千个小区间 U，把 (|U|, μ(U)) 画成散点，和曲线 |U|d 比。
抽样区间数
质量分布原理实测（双对数）：每个点是一个随机区间 U。 红线 = |U|d，橙线 = 4|U|d（理论上界）。 所有点都压在橙线下 ⟹ Hd(C) ≥ 1/4 > 0。另画两条斜率 s≠d 的参照：换成 s>d 时点会冲到线上方（找不到常数 c），s<d 时不等式松到无用。
比值 μ(U)/|U|s 的最大值随 s：s ≤ d 时有限（不等式成立）， s > d 时随抽样越细越往上跑 ⟹ 发散。临界 s 又一次等于 d。
三种维数什么关系？　dim拓扑 ≤ dimH ≤ dimbox（下盒 ≤ 上盒）。 对"乖"的自相似集（满足开集条件）三者中后两个相等，所以 ② 的实测能验证 ① 的公式。
但它们真会不等：取 A = ℚ∩[0,1]。A 可数 ⟹ Hs(A)=0 对一切 s>0 ⟹ dimH = 0； 可 A 稠密，任何 ε 网格的每个格子都非空 ⟹ N(ε)=1/ε ⟹ dimbox = 1。 盒计数不管"重数"、只管"占不占格子"，所以它会被稠密的稀疏集骗到；豪斯多夫维数靠的是可数多个任意大小的覆盖块，不会。 这也是为什么实测出来的斜率要叫"盒计数维数"而不能直接叫"豪斯多夫维数"。
