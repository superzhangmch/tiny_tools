中心极限定理的证明发生在频域 —— 特征函数视角 把 φ(t)=E[eitX] 的那几步逐个画出来看

记号：φY(u)=E[eiuY] 是单个观测的特征函数，u 是频率、无量纲，恒有 φY(0)=1、|φY|≤1。 t 是和 Sn 的特征函数 φSₙ(t) 的自变量，两者由 u = t/√n 相联。 T=10 是我们关心的频率范围（重建 N(0,1) 只需 |t|≲8）。

把「精确」和「近似」分开看 —— 这是本页的全部用意：
① → ④ 全部精确，一点近似都没有。 ①标准化密度 → ②求特征函数 φY（傅里叶变换）→ ③独立相加⟹相乘取幂 φSₙ(t)=[φY(t/√n)]n → ④逆变换回 Sn 的密度。 到④为止 Sn 的分布已被完全确定，这跟 CLT 还没关系。
⑤ → ⑥ 才引入近似。 ⑤把 φY 在原点截断到前两项 1−u²/2 → ⑥截断版取 n 次幂得 [1−t²/2n]n → e−t²/2，再回头和③的精确曲线比。
CLT 的内容就是：③那条精确曲线自己趋向 e−t²/2；而⑤的截断误差即使被 n 次幂放大也仍然趋于 0 —— 所以近似只是证明的手段，结论是精确的。最后由 Lévy 连续性定理把频域收敛翻回分布收敛。

哪些是精确算的、哪些是数值积分（别把数值误差当成理论误差）：
· 精确：手绘的形状不是"被近似"，而是被当作总体的定义 —— 你画的 200 根柱子定义了一个分段均匀密度（第 j 格 = 宽 h=1/200、高 wj/h 的一段均匀分布）。 一旦这么定义，下面全是闭式，没有任何求积：
  μ = Σwjcj， σ² = Σwj[(cj−μ)²+h²/12]， m₃ = Σwj[(cj−μ)³+3(cj−μ)h²/12]， m₄ = Σwj[(cj−μ)⁴+6(cj−μ)²h²/12+h⁴/80]（h²/12 是格内那段均匀自己的方差）
  φY(u) = sinc(u·h/2σ) · Σj wj eiuzj —— 前面那个 sinc 正是"每格是一段均匀"贡献的因子，后面是有限和。
  自检：均匀预设此时就是精确的 U[0,1] —— 程序算出 σ=0.28867513（=1/√12）、 超额峰度 =−1.200000、偏度 =2×10−15；φ 与解析式 sin(√3u)/(√3u) 偏差 1.6×10−15。 伯努利那档是真原子（h=0 ⟹ sinc≡1），偏度 1.960392、超额峰度 1.843137，与解析值完全相同。
φSₙ=[φY]n 走极坐标 + 相角 unwrap，与直接复数连乘对照偏差仅 10−15； μ、σ、偏度、峰度都是有限和；e−t²/2、1−u²/2、正态密度都是解析式。 伯努利那档有解析特征函数，程序值与它偏差 0.0。
· 数值积分只有一处：④的逆变换（以及基于它的 KS）。 求积误差已收敛（网格加密 4 倍后变化 10−15）；截断误差只在 n 很小时才可见 —— n=1 时把 T 加倍会让密度变 5×10−3（φY 衰减慢，丢掉 |t|>T 会有 Gibbs 振铃）， n=9 时降到 3×10−9，n=100 时 9×10−16。

③ 相乘取幂 · 精确　φSₙ(t) = [φY(t/√n)]n —— 这一步来自独立性，是恒等式，不是近似。
横轴 t（|t|≤T=10），纵轴取值。■ 蓝 = 精确 Re φSₙ／ ■ 红虚 = e−t²/2（目标）。 ■ 细虚 = Im φSₙ（偏度住在这里）。 蓝线自己贴向红线、细虚线自己压平，这件事就是 CLT。
④ 逆变换 · 全页唯一的数值积分　 把③那条曲线逆傅里叶变换，得 Sn 的真实密度： f(x)=(1/2π)∫−TTφSₙ(t)e−itxdt，梯形法 2401 点。
横轴 x（同①的单位），纵轴密度。■ 蓝 = Sn 精确密度／ ■ 红虚 = 标准正态密度。 一个样本都没抽 —— 这是算出来的，不是抽出来的。
n=1 时这条蓝线就是①那条密度本身，只是横轴换成了标准化单位 (x−μ)/σ。 对照两图时把左右两端概率为 0 的空白裁掉，形状应当完全重合 （①的横轴是原始 [0,1]，本图是 ±4.5σ，所以本图两侧会多出一大片零）。 例：均匀总体此时是个方块，高 1/(2√3)=0.2887、宽 ±√3=±1.732。 两点留意：傅里叶积分在跳跃处必然取两侧极限的平均（方块的竖边会"切角"，这是对的，不是误差）； n 小时 φ 只按 1/t 衰减、截断会留波纹 —— 本图对 n≤8 单独用 T=120 把波纹从 0.016 压到 0.0013。
⑤ 近似登场　把②的 φY 在原点截断到前两项：φY(u) ≈ 1−u²/2。
横轴 u，橙色那排是对应的 t=u·√n。 ■ 蓝 = 精确 Re φY／ ■ 红虚 = 截断的 1−u²/2／ ■ 黄底 = 当前 n 真正用到的窗口 |u|≤T/√n。
拖大 n → 黄窗口按 1/√n 收缩 → 窗口内两线越来越贴。 窗口外贴不贴无关紧要，那里的 u 永远不会被代入。
⑥ 近似的后果　把⑤那条截断版取 n 次幂：[1−t²/2n]n，与③的精确曲线并排。
■ 蓝 = 精确 φSₙ／ ■ 橙 = 截断版 [1−t²/2n]n（实值）／ ■ 红虚 = e−t²/2／ ■ 细虚 = Im φSₙ。
偏度只影响虚部（展开的 −iγ₁u³/6 是纯虚的），所以比较必须用复模 —— 只看实部会把 γ₁ 那一项整个漏掉，误判成收敛更快。
两件事同时发生：橙线 →红线（这是 (1+a/n)n→ea 的初等极限）； 橙线也→蓝线（截断误差被 n 次幂放大后仍趋 0）。夹在中间的蓝线因此被逼向红线。
灰竖线 = |t|=√(2n)：截断多项式在此变负，超出它近似彻底失效 —— 这也是小 n 时 ⑤⑥ 难看的原因。
