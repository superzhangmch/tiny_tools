中心极限定理：手绘一个分布，看 n 个的均值被揉成正态

预设: n =
母分布 f(x)（在这里拖动手绘，画什么形状都行；柯西预设为解析分布，重尾在画布外才是重点，不可手绘）
n 个独立样本的均值的直方图（持续累计中）；红曲线 = 理论正态 N(μ, σ²/n)（由母分布的实测矩算出，不是拟合直方图）；柯西时红曲线 = 柯西密度本身
定理：只要母分布方差有限，x̄ₙ = (X₁+…+Xₙ)/n 标准化后 → N(0,1)，与母分布形状无关。 拉 n：n=1 是你画的原样；n=2 开始平滑（卷积）；n≈30 基本认不出出身。实测偏度按 1/√n、超额峰度按 1/n 衰减（读数在上方，可对照）。 反例：柯西分布方差无穷，n 个柯西的均值仍是同一个柯西——直方图随 n 纹丝不动，CLT 的"方差有限"前提不是套话。 诚实声明：直方图、偏度、峰度、视野外占比全部来自实际采样计数；正态曲线的 μ、σ² 来自你画的密度的精确积分（分段常数密度的解析矩），不是对直方图的拟合。
