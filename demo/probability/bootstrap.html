Bootstrap：上帝不给你第二份样本，你就自己抽自己

总体: 样本量 n: 统计量:
你手里唯一的一份样本（每点一个观测；bootstrap 只能看到这些）
Bootstrap 世界：从这份样本有放回重抽 n 个 → 算统计量，重复上万次
上帝视角：每次从真总体抽全新的 n 个 → 统计量的真实抽样分布（现实中不可得）
问题：统计量（均值、中位数…）离真值有多远？答案需要"统计量的抽样分布"，但那要无数份新样本——你只有一份。 Efron 1979：把这份样本当作总体的替身，有放回重抽——左图就这样凭一份数据"硬拽"出了右图的近似。 对照两图的实测标准误 SE 和 95% 区间（读数在上方）：均值/中位数/标准差下相当接近——这就是为什么它无处不在。 失灵案例：切到"最大值"——bootstrap 的最大值永远 ≤ 样本最大值，左图变成贴在样本最大值上的几根离散尖刺 （P(重抽 max = 样本 max) = 1−(1−1/n)ⁿ ≈ 63%），右图却是连续分布且延伸到样本没见过的地方。 教训：bootstrap 靠"样本 ≈ 总体"，在分布的边缘（极值、重尾）这个替身骗不了人。按"重抽一份原始样本"再看：换一份样本，左图整体搬家——bootstrap 自身也有围绕真相的抖动。
