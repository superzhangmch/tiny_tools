集中不等式（concentration inequalities）—— 对任意分布都成立的界

X = 从总体抽的一个观测（①画的是它，原始单位）。Z = (X−μ)/σ 是标准化后的它， E[Z]=0、Var[Z]=1，②③④ 用 Z。k = 偏离几个 σ。
Z̄ = n 个观测标准化后的均值，Var[Z̄]=1/n；ε = 均值偏离几个 σ，⑤⑥ 用它。
总体
k 采样
① 总体（原始单位）　蓝 = 密度，绿 = μ， 红虚 = μ±kσ，红区 = Chebyshev 管的那块尾部。按住鼠标可改。
② Chebyshev：P(|Z| ≥ k) ≤ 1/k²　 红 = 界（与分布无关）／ 蓝 = 真值／绿 = 实测。 蓝线永远在红线下；最坏总体会在某个 k 上贴住。
③ 这个界松了多少倍 = (1/k²) ÷ P(|Z|≥k)　 正态在 k=2 松 5.5 倍，k=4 松约 4000 倍。灰线 = 1，即取等号。
④ 单边：Cantelli P(Z ≥ k) ≤ 1/(1+k²)　 红 = Cantelli／蓝 = 真值／ 绿 = 实测／品红点 = 把双边界折半 1/(2k²) —— 那一步只对对称分布成立，一般情况下它比真值还小。
⑤⑥ 专用　ε ②③④ 的不等式里没有 ε —— 它只出现在对均值的界里
⑤ 对均值用一次 Chebyshev ⟹ 弱大数定律　Var[Z̄]=1/n ⟹ P(|Z̄| ≥ ε) ≤ 1/(nε²) → 0。
红 = 1/nε²（幂律，斜率 −1）／ 紫虚 = CLT 2Φ(−ε√n)（指数衰减）／ 绿 = 实测。差距越拉越大。
⑥ Hoeffding：P(|Z̄| ≥ ε) ≤ 2e−2nε²/R²，R = 标准化后的极差。
橙 = Hoeffding／红 = Chebyshev／ 绿 = 实测。多买一条"有界"假设，把幂律换成指数； R 大的总体它反而更松。
界为什么这么松，以及为什么不能再改进
Chebyshev 在 k=2 只给出 ≤25%，正态的真值是 4.55%。松不是证明的毛病 —— 存在分布把它恰好撑满：
三点：P(±k)=1/(2k²)、P(0)=1−1/k² ⟹ 均值 0、方差 1， 而 P(|Z|≥k)=1/k²，正好等于 Chebyshev 界。
两点：P(+k)=1/(1+k²)、另一点在 −pk/(1−p) ⟹ P(Z≥k)=1/(1+k²)，正好等于 Cantelli 界。
做法是把该跑到尾部的概率全顶在 k 那一点，剩下的塞在均值处省方差。上面那两个按钮就是它们， 按当前 k 构造，也只在那个 k 上贴住。（不算人造：伯努利 p 本身就是 Cantelli 在 k=√((1−p)/p) 处的最坏总体，p=0.15 ⟹ k=2.38。）
所以"松"是「只知道 μ 和 σ²」的代价。想更紧，只能多买一条假设：有界 ⟹ Hoeffding（⑥， 幂律变指数）；n→∞ ⟹ CLT（⑤，但那是近似，不是界）。
